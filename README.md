# 資産管理簿

口座ごとの残高を好きな日に記録し、純資産・資産の内訳・推移を確認できる個人用の資産管理Webアプリです。
データはすべて端末のブラウザ内（localStorage）に保存され、外部には送信されません。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | アプリ本体（HTML・CSS・JavaScriptを1ファイルに収録） |
| `manifest.webmanifest` | ホーム画面に追加したときのアプリ情報 |
| `apple-touch-icon.png` | iPhoneのホーム画面用アイコン（180×180） |
| `icon-192.png` / `icon-512.png` | その他の端末用アイコン |

## GitHub Pagesで公開する

1. GitHubで新しいリポジトリを作成する（例：`shisan-kanribo`）
2. このフォルダの中身をすべてリポジトリの直下にアップロードする
3. リポジトリの **Settings → Pages** を開き、**Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存する
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになる

## iPhoneで使う

1. SafariでGitHub PagesのURLを開く
2. 共有ボタン →「ホーム画面に追加」
3. 以降はホーム画面のアイコンから起動する

ホーム画面から使うと、Safariの自動データ削除の対象になりにくくなります。

## データについて

- データは「そのURL × その端末のブラウザ」ごとに保存されます。URLを変えたり（リポジトリ名の変更など）、別の端末で開いたりすると、データは引き継がれません。
- 機種変更・Safariのデータ消去・アプリの削除でデータは消えます。**設定 → バックアップ**から定期的に書き出してください。
  - 「ファイルに保存」：共有シートから「ファイル」アプリなどに保存
  - 「テキストをコピー」：メモアプリなどに貼り付けて保管
- 復元は **設定 → バックアップ** の「ファイルから復元」または「テキストを貼り付けて復元」から行います。

## 機能

- 口座の登録（預金・現金・株式/投資信託・年金・保険・不動産/車・ポイント・その他・負債/ローン）
- 任意の日付での残高記録（入力しなかった口座は直前の記録の値を引き継ぐ）
- 記録の履歴と、前回からの増減
- 純資産・資産の内訳（円グラフ）・推移（直近12回の記録）
- JSONでのバックアップと復元
- ダークモード対応
